# M08 — Exercícios

## E12.1 — Modelo de ameaça

Compare cookie `HttpOnly` e token no cabeçalho para uma API consumida por um sistema externo.
Escolha uma opção e registre vantagens, riscos e mitigação.

## E12.2 — Matriz de autorização

Monte uma matriz papel × rota × método para dois papéis. Implemente e teste pelo menos seis
combinações, incluindo `401` e `403`.

## E12.3 — Não vazar segredo

Inspecione respostas de cadastro, login e consulta de usuário. Garanta que senha, hash, token
interno e dados desnecessários não apareçam no DTO de saída.
